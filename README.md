# Nuança

Мягкий дневник эмоций для женщин: отмечай оттенки чувств, силу и короткие заметки. Данные хранятся локально в браузере.

## Запуск

```bash
npm install
npm run dev
```

Открой адрес из терминала (обычно http://localhost:5173).

## Возможности

- Выбор из 10 эмоций с цветовыми оттенками
- Интенсивность 1–10 и необязательная заметка
- Журнал записей и ландшафт настроения за 7 дней
- Короткие мягкие инсайты по неделе
- Светлая и тёмная тема
- Ежедневные напоминания (уведомления браузера, пока открыта вкладка)
- Экспорт журнала в PDF через печать / «Сохранить как PDF»
